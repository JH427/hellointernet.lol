01 / Local AI

Horizon Code ↗

Implemented foundation · experimental routing

An agent loop with a verification gate.

A Go coding harness for llama.cpp: typed tools, bounded execution, persistent evidence, and a terminal UI. Workspace changes require a passing verification command before completion.

Decision routing is opt-in and experimental—not a demonstrated across-the-board improvement.

02 / Machine-made media

Sloperator ↗

Early alpha · CPU-safe foundation

Treat the timeline as a contract.

A CLI for frozen show manifests, input hashes, resource preflight, and CPU-only ffmpeg montage assembly. Canonical audio stays intact while picture gets stitched and validated.

GPU generation is roadmap work, not a shipped capability. The run command plans; it does not render.

Inspect: Show schema + architecture + test suite ↗

03 / Useful glue

FAE PDF ↗

Small standalone toolkit

Structured content in. A document out.

A stateless Python CLI that pairs Jinja2 HTML templates with Playwright’s Chromium PDF printing. File or inline JSON input, A4 output, no server.

A rendering tool, not a hosted document service. Templates and content are supplied by the caller.
