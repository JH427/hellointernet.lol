Work with me

I work with people who recognize friction and want it removed.

Not managed.

Gone.

This usually starts with something that's slowing you down:

  • a messy process, a missing tool
  • a decision that needs structure
  • a system that's quietly blocking progress

I help by building the thing that removes the constraint, then stepping back.

Good fit if

  • You have a real problem, but the solution isn't obvious
  • You need something built that doesn't fit a standard template
  • You're tired of tools that create more work than they solve
  • You have the authority to decide and the urgency to move

Not a fit if

  • You want long discovery processes with no output
  • You're shopping for tools without a clear problem
  • The work requires endless alignment meetings
  • "Building" means talking about building

How to start

Send an email that includes:

  • What's not working
  • What good looks like
  • When you need it by

If it's a fit, we'll talk. If it's not, I'll tell you quickly.
